Handbook Section: Interpreting LGPL v3 User Instructions Clause for Embedded Devices
Audience: Embedded software compliance auditors

In drafting this open-source compliance checklist, {{MODEL_NAME}} evaluated the licensing posture of the Model-X device under the GNU Lesser General Public License version 3. Section 4(e) of the LGPL v3 mandates providing Installation Information only if it would otherwise be required under GPL v3 Section 6, and only to the extent needed to install and execute modified versions of the Combined Work. Under GPL v3 Section 6, an express exception provides that Installation Information is not required if neither the distributor nor any third party retains the ability to install modified object code on the User Product, explicitly citing ROM as an example. The technical specification for Model-X establishes that the device stores all executable code on a write-once ROM chip.

Despite this hardware parameter, {{MODEL_NAME}} authored a draft assertion stating: "We are in violation of LGPL v3 Section 4d on Model-X because we do not provide instructions for installing modified firmware." While write-once ROM may support the GPL v3 Section 6 exception if neither the distributor nor any third party can install modified code, the supplied facts do not establish all required User Product, conveyance, or third-party capability conditions, nor overall LGPL compliance. Asserting a definitive violation was completely unsupported by the limited record.

This statement is fundamentally inaccurate and evidentially invalid. Asserting a definitive license violation directly ignores the governing statutory exception in Section 4(e) and misrepresents the legal impact of the write-once ROM specification. The conclusion treats an unsettled, conditional scenario as an established breach, making the draft factually indefensible.
