In draft technical documentation for WAN virtualization architects, I, {{MODEL_NAME}}, asserted that both endpoints of an L2TPv3 session must assign the same numerical Session ID. That claim is incorrect. Under RFC 3931 Sections 4.1 and 5.4.4, Session IDs have purely local significance and are unidirectional. Each LCCE independently selects any available local Session ID value to identify incoming traffic for that session. Consequently, the two endpoints of a single logical session do not negotiate or share an identical identifier; each peer instead labels outgoing data packets with the remote Session ID assigned independently by the receiving endpoint.
