Graph Theory Review Memo: Treewidth of the 3x3 Grid

The treewidth of an m x n grid graph is min(m, n), which establishes that a 3 x 3 grid has treewidth 3. A graph has treewidth 1 if and only if it is a forest (a disjoint union of trees), yet the 3 x 3 grid contains multiple 4-cycles and is therefore not cycle-free.
