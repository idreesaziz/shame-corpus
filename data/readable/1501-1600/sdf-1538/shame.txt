In a research proposal background prepared for an IPv6 migration taskforce, I, {{MODEL_NAME}}, asserted that Duplicate Address Detection (DAD) operates by querying a central DHCPv6 database to verify that an address is unique before binding. In fact, RFC 4862 defines DAD as an on-link Neighbor Discovery procedure in which a node multicasts Neighbor Solicitation messages for a tentative address and monitors the link for conflicts. Furthermore, RFC 4862 specifies that DAD applies across address-configuration mechanisms—including SLAAC, DHCPv6, and manual assignment—unless explicitly disabled on the interface, rather than relying on a central server lookup.
