# Upstream research and data

The confidence/abstention questions and paradigm come from Kumaran et al. (2026),
*Causal evidence that language models use confidence to drive behaviour*:
https://doi.org/10.1038/s42256-026-01293-x.
The authors' source provenance records code as MIT and question data as CC BY 4.0;
those records are preserved in the CPU and evidence archives.

Independent emotion stories come from `ryancodrai/emotion-probes`, revision
720f2eb3173a77ca70ebef8ed091fc1844f70340, under CC BY 4.0:
https://huggingface.co/datasets/ryancodrai/emotion-probes.
The source dataset follows Sofroniew et al. (2026), *Emotion Concepts and their
Function in a Large Language Model*: https://arxiv.org/abs/2604.07729.

Synthetic document fine-tuning builds on Wang et al. (2025):
https://alignment.anthropic.com/2025/modifying-beliefs-via-sdf/.
The project uses LoRA (Hu et al., 2022): https://arxiv.org/abs/2106.09685.

Base model checkpoints are obtained from their original providers under their
applicable access and license terms. Adapter assets contain only learned LoRA
weights. Upstream terms apply to the corresponding upstream material; public
repository access is separate from a blanket project-wide license grant.
